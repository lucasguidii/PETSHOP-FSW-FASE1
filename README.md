# Petshop Amigo Fiel — Fase 1 (PUCRS Online)

Autor: Lucas Guidi Leite

Projeto acadêmico da disciplina Fundamentos de Sistemas Web. Todas as páginas utilizam HTML puro, sem CSS, Bootstrap ou JavaScript.

## Arquivos

- `index.html`: página inicial e produtos em destaque.
- `acessorios.html`: dois acessórios.
- `racoes.html`: duas rações não perecíveis.
- `higiene.html`: dois itens de higiene e limpeza.
- `servicos.html`: serviços de banho e tosa com e sem tele-busca.
- `contato.html`: informações do projeto e contato demonstrativo.
- `imagens/`: ilustrações vetoriais SVG locais (sem dependência de internet).

## Como testar

Abra `index.html` em um navegador, utilize os links e confira cada página. Não existem carrinho, compras ou agendamento nesta fase.

## Como publicar no GitHub Pages

1. Entre em github.com usando sua conta.
2. Crie um repositório público, por exemplo `PETSHOP-FSW-FASE1`.
3. Envie **o conteúdo da pasta `site` para a raiz** do repositório (inclusive a pasta `imagens`).
4. Em **Settings > Pages**, escolha **Deploy from a branch**, branch **main** e pasta **/(root)**; salve.
5. Confira o endereço exibido pelo GitHub Pages. Teste a página inicial, imagens e navegação.
6. Copie o endereço real do repositório e o endereço real do site para o relatório da faculdade, substituindo as marcações PENDENTE.
7. Exporte novamente o relatório para PDF e envie apenas o PDF no ambiente acadêmico; clique em **Submeter**.

**Atenção:** publicar o site exige acesso autenticado à sua conta; estes passos não foram executados automaticamente. Links de repositório e de Pages ainda precisam ser confirmados.
